# Zer0-WR

Lecteur de web-radio simple et léger, conçu pour lire des flux audio directement dans le navigateur.

## Fonctionnalités

- Sélection d'une radio dans une liste
- Lecture audio via le lecteur HTML5
- Ajout de radios personnalisées par nom et URL
- Aucune dépendance externe ni installation requise
- Compatible avec les navigateurs modernes

## Prérequis

- Un navigateur web moderne
- Accès à des flux audio (URL de type MP3, AAC, etc.)

## Utilisation

1. Clonez ce dépôt :
   ```bash
   git clone https://github.com/Richerrail/Zer0-WR.git
   ```
2. Ouvrez le fichier `index.html` dans votre navigateur.
3. Sélectionnez une radio dans la liste ou ajoutez-en une nouvelle avec son nom et son URL.
